# NeuroDictate - бесплатная локальная диктовка для Mac

Приложение для диктовки голосом. Зажимаешь **Option (⌥)** в любом приложении,
говоришь, отпускаешь - и через пару секунд готовый текст появляется там, где
стоял курсор. Telegram, браузер, заметки, почта - работает везде.

Главное: **все происходит на твоем Mac**. Голос никуда не отправляется,
подписку платить не надо, интернет нужен только один раз - скачать модели.

Как это работает под капотом:

1. **OpenAI Whisper** (модель large-v3-turbo через mlx-whisper, оптимизация под
   чипы Apple) превращает речь в текст - с пунктуацией, на русском, английском
   и еще 100 языках.
2. **Gemma 3** (локально через Ollama, по желанию) приглаживает результат:
   исправляет ослышки и грамматику, убирает «эээ» и повторы.

## Что нужно

- Mac на **Apple Silicon** (M1, M2, M3, M4) - на Intel и Windows не заработает;
- Python 3.10 или новее ([скачать](https://www.python.org/downloads/), если нет);
- ~2 ГБ на диске для модели распознавания (+3 ГБ, если захочешь авторедактуру);
- 15 минут на установку.

## Установка

1. Скачай проект: зеленая кнопка **Code → Download ZIP** (или `git clone`),
   распакуй в удобную папку.
2. Даблклик по **`install.command`**. Если Mac ругается на «неустановленного
   разработчика» - правый клик по файлу → Открыть. Скрипт создаст окружение
   и скачает модель (~1.6 ГБ), подожди несколько минут.
3. Даблклик по **`build_app.command`** - соберет `NeuroDictate.app`, положит
   его в «Программы», включит автозапуск и запустит. В меню-баре (справа
   наверху, рядом с часами) появится значок ⌛, а затем 🎤.
4. Выдай разрешения приложению **NeuroDictate** в Настройки →
   Конфиденциальность и безопасность (macOS предложит сама при первой
   диктовке, либо добавь через «+» из папки «Программы»):
   - **Микрофон** - записывать голос;
   - **Универсальный доступ** - вставлять текст;
   - **Мониторинг ввода** - слышать горячую клавишу.
5. Перезапусти приложение: меню 🎤 → Выход, потом открой NeuroDictate из
   Launchpad или «Программ».
6. Открой Заметки, зажми Option, скажи фразу, отпусти. Магия!

Папку проекта после сборки можно оставить где угодно - приложение
самостоятельное. Настройки и лог живут в
`~/Library/Application Support/NeuroDictate/`.

<details>
<summary>Запасной вариант без сборки приложения</summary>

Можно не собирать `.app`, а запускать скриптом: `start.command` (запуск),
`stop.command` (остановка), `autostart.command` (автозапуск через Терминал).
Разрешения в этом случае выдаются Терминалу, а настройки и лог лежат
рядом со скриптами.
</details>

### Авторедактура (по желанию, но советую)

Чтобы текст был не «как сказала», а «как написала бы», поставь Ollama и
маленькую локальную модель-редактора:

```bash
brew install ollama
brew services start ollama
ollama pull gemma3:4b
```

Все, NeuroDictate подхватит ее сам. Если Ollama нет - приложение просто
вставляет текст без редактуры, ничего не ломается.

### Автозапуск при включении Mac

Даблклик по `autostart.command` - и больше вообще ничего запускать не надо.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| Зажать Option и говорить | Идет запись (значок 🔴) |
| Отпустить | Текст распознается (⏳) и вставляется |
| Коротко нажать Option | Запись «надолго», руки свободны |
| Нажать Option еще раз | Стоп, текст вставляется |
| Esc во время записи | Отмена без вставки |

Меню по клику на 🎤: скопировать последний текст, язык (авто/русский/
английский), авторедактура вкл/выкл, звуки вкл/выкл.

Настройки - в `config.json`: горячая клавиша, модель, язык, промпт редактора,
максимальная длина записи. После правки перезапусти приложение.

## Если что-то не работает

- **Значок есть, но Option не реагирует** - не выдан «Мониторинг ввода».
- **Записывает, но текст не вставляется** - не выдан «Универсальный доступ».
  Сам текст не потерялся: меню 🎤 → «Скопировать последний текст».
- **Вставляется пустота** - проверь разрешение на микрофон, говори ближе.
- Подробности всегда в логе `~/Library/Application Support/NeuroDictate/neurodictate.log` -
  покажи его своему AI-ассистенту, он разберется. Если там при запуске
  написано «This process is not trusted» - разрешения до приложения не дошли.
- Пересобрать приложение после правок кода: снова `build_app.command`.
  Важно: после пересборки macOS считает приложение новым, и разрешения
  (Универсальный доступ, Мониторинг ввода, Микрофон) надо выдать заново.
  Старые записи можно снести командой
  `tccutil reset Accessibility com.neuralprofit.neurodictate` (и так же для
  `ListenEvent` и `Microphone`).
